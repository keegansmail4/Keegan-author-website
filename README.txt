# Keegan Author Website

Open `index.html` in a web browser to preview the site.

Files:
- index.html — website content
- style.css — design and responsive layout
- hero-sunset.jpeg — uploaded sunset/lake photograph used as the hero image

Before publishing:
1. Replace `your-email@example.com` in index.html with the author's email.
2. Replace placeholder "Coming soon" links with published story URLs when ready.
3. Add an author headshot/about photo if desired.
4. Upload the folder to a web host such as GitHub Pages, Netlify, Vercel, or a traditional hosting provider.
